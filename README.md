# AstroVeda

AstroVeda is a modern, responsive astrologer website built with React.js and TypeScript. It provides a clean UI for exploring astrologers, astrology services, profiles, and consultation options.

## 🚀 Setup

```bash
git clone <github-repo>
cd astroveda
npm install
npm run dev
```

## 🛠️ Tech Stack

* React.js
* TypeScript
* Vite
* HTML5
* CSS3
